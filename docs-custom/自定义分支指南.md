# 自定义分支指南

## 一、分支说明

基于 [RustDesk 官方仓库](https://github.com/rustdesk/rustdesk) fork，在 `custom` 分支上做了以下自定义：

| 改动 | 说明 |
|------|------|
| **Headless SDK** | WebSocket 控制的远程桌面后端，用于 Python 脚本自动化 |
| **触摸手势交换** | Android 端单指移动画布、双指远端鼠标拖拽 |
| **精简 CI** | 手动触发，只编 Windows x86_64 + Android arm64-v8a |

分支策略：

```
master   ← 官方代码，只从 upstream pull，不手动改
custom   ← master + 自定义改动，日常开发
```

## 二、改动文件清单

| 文件 | 改动 |
|------|------|
| `Cargo.toml` | 加 `[[bin]] headless_sdk` |
| `src/lib.rs` | 3 个模块改为 `pub mod` |
| `src/headless_sdk.rs` | 新建，Headless SDK 核心模块 |
| `src/bin/headless_sdk.rs` | 新建，二进制入口 |
| `src/ui_session_interface.rs` | 加 `input_key_map()` 方法 |
| `src/client/io_loop.rs` | 加像素缓冲区软件解码 fallback |
| `build.py` | 去掉 2 处 `--locked` |
| `flutter/lib/common/widgets/remote_input.dart` | 触摸手势交换 |
| `flutter/lib/mobile/widgets/gesture_help.dart` | UI 描述文字交换 |
| `flutter/ndk_*.sh` ×4 | 去掉 `--locked`，加 `--lib` |
| `.github/workflows/flutter-build-lite.yml` | 新建，精简 CI |

## 三、打包

### 本地 Sciter 版

```powershell
cd D:\Projects\rustdesk
. .\env.ps1
cargo update
python build.py --portable
```

### CI Flutter 版

Actions → Flutter Build Lite → 选 `custom` 分支 → Run

## 四、同步官方

```bash
git checkout master
git pull upstream master
git checkout custom
git merge master
git push origin custom
```
