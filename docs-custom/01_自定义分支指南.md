# 自定义分支指南

## 一、分支说明

基于 [RustDesk 官方仓库](https://github.com/rustdesk/rustdesk) fork，在 `custom` 分支上做了以下自定义：

| 改动 | 说明 |
|------|------|
| **Headless SDK** | WebSocket 控制的远程桌面后端，用于 Python 脚本自动化 |
| **触屏模式手势改造** | Android 端重新设计触摸手势，适配远程操控游戏场景 |
| **游戏快捷键定制** | 底部快捷键栏替换为 QQ三国常用按键 |
| **独立快捷栏按钮** | 新按钮点开快捷键栏，不弹出输入法 |
| **画布边界约束** | 缩放/拖动自动居中，不拖出黑边 |
| **精简 CI** | 手动触发，只编 Windows x86_64 + Android arm64-v8a |

分支策略：

```
master   ← 官方代码，只从 upstream pull，不手动改
custom   ← master + 自定义改动，日常开发
```

## 二、改动文件清单

### Rust 层（Headless SDK）

| 文件 | 改动 |
|------|------|
| `Cargo.toml` | 加 `[[bin]] headless_sdk`，加 `futures`/`tokio-tungstenite`/`tungstenite` 依赖 |
| `src/headless_sdk.rs` | 新建，Headless SDK 核心（WebSocket 服务器、协议处理） |
| `src/bin/headless_sdk.rs` | 新建，入口 |
| `src/lib.rs` | 3 个模块 `client`/`ui_interface`/`ui_session_interface` 改为 `pub mod` |
| `src/ui_session_interface.rs` | 加 `input_key_map()` 公开方法 |
| `src/client/io_loop.rs` | 加非 VRAM/Flutter 下的 `on_rgba` 软件解码回退 |
| `build.py` | 去掉所有 `--locked` 标志 |
| `flutter/ndk_*.sh` ×4 | 去掉 `--locked`，加 `--lib` |

### Flutter 层（触屏手势 + UI）

| 文件 | 改动 |
|------|------|
| `flutter/lib/common/widgets/remote_input.dart` | 触屏手势全部改造（见下文手势表）、鼠标模式缩放死区平滑 |
| `flutter/lib/common/widgets/gestures.dart` | 双指缩放首帧死区跳变修复 |
| `flutter/lib/models/model.dart` | `minScale` 改为 `min(xscale, yscale)`、`panX`/`panY` 加边界 clamp（画面小则居中、大则不拖出黑边）、`updateScale` 加位置 clamp |
| `flutter/lib/mobile/widgets/gesture_help.dart` | 手势帮助界面文案更新（6 个手势），新增长按拖拽条目 |
| `flutter/lib/mobile/pages/remote_page.dart` | 快捷键栏替换为游戏常用键、新增 ␣ 按钮（弹出快捷键不弹输入法） |

### CI

| 文件 | 改动 |
|------|------|
| `.github/workflows/flutter-build-lite.yml` | 新建，`workflow_dispatch` 手动触发，编 Windows + Android arm64-v8a |

## 三、触屏模式手势

| 手势 | 功能 | 说明 |
|------|------|------|
| 单指点击 | 左键 | 点击屏幕对应位置 |
| 单指长按（1.1s 不动） | 右键 | 500ms 长按识别 + 600ms 定时器 |
| 单指长按拖拽 | 鼠标拖拽 | 长按后移动手指进入拖拽，不触发右键 |
| 单指移动 | 画布移动 | 拖动视口 |
| 双指捏合 | 画布缩放 | 以双指中点为中心缩放 |
| 三指垂直滑动 | 鼠标滚轮 | |

鼠标模式手势保持官方行为不变。

## 四、底部快捷键栏

非 Android 对端时，底部栏按钮顺序：

```
[× 关闭] [📺 选项] [⌨ 键盘] [␣ 快捷栏] [👆 触屏/鼠标] [💬 聊天] [⋯ 更多]
```

- **键盘**：弹出输入法 + 快捷键栏
- **␣ 快捷栏**：只弹出快捷键栏，不弹输入法

### 快捷键布局

```
修饰键:  Ctrl   Alt   Shift   Win/Cmd
控制:    [Fn]  [📌 图钉]  [...]

行1: G-对话  I-活动  O-军团  M-地图  '-货栈  N-自动
行2: Enter  Q  W  A  S  Z  X  C  V
行3: ←  ↑  ↓  →  Space  Esc
```

Fn 区保留 F1-F12。组合键（Ctrl+C/V/S）已注释待用。

## 五、打包

### CI（Actions → Flutter Build Lite → 手动触发）

四个独立打包选项，按需勾选：

| 选项 | 产物 |
|------|------|
| RustDesk Windows (Flutter) | 完整 Windows 安装包 |
| RustDesk Android arm64-v8a | Android APK |
| headless_sdk Windows x64 | 纯控制端（Windows） |
| headless_sdk Linux arm64 | 纯控制端（N1/Armbian） |

只打 headless 时取消前两项，单独勾选对应平台即可。
