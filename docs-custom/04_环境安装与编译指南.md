# RustDesk 环境安装与编译指南

> 自定义分支（GoBelieveBaoZzz/rustdesk），D 盘环境。Headless SDK + 触屏手势改造 + QQ三国键盘定制。

## 一、环境安装

### 1.1 Rust 工具链

```powershell
# 先设环境变量，再装 rustup
New-Item -ItemType Directory -Force -Path D:\rust\toolchains
New-Item -ItemType Directory -Force -Path D:\rust\cargo
[Environment]::SetEnvironmentVariable("RUSTUP_HOME", "D:\rust\toolchains", "User")
[Environment]::SetEnvironmentVariable("CARGO_HOME", "D:\rust\cargo", "User")

# 下载并安装（要重新开一个终端让环境变量生效）
Invoke-WebRequest -Uri "https://static.rust-lang.org/rustup/dist/x86_64-pc-windows-msvc/rustup-init.exe" -OutFile "D:\rust\rustup-init.exe"
$env:RUSTUP_HOME = "D:\rust\toolchains"
$env:CARGO_HOME = "D:\rust\cargo"
D:\rust\rustup-init.exe -y --default-toolchain stable --profile default
```

### 1.2 VS Build Tools 2022（MSVC 链接器）

```powershell
Invoke-WebRequest -Uri "https://aka.ms/vs/17/release/vs_buildtools.exe" -OutFile "D:\rust\vs_buildtools.exe"
D:\rust\vs_buildtools.exe --quiet --wait --norestart `
    --installPath "D:\VS\BuildTools" `
    --add Microsoft.VisualStudio.Workload.VCTools `
    --includeRecommended
```

### 1.3 LLVM / libclang（bindgen 依赖）

⚠️ **只能用 LLVM 19.x**，LLVM 22 与 bindgen 0.71.1 不兼容。

```powershell
winget install --id LLVM.LLVM --version 19.1.7 --location "D:\LLVM19"
[Environment]::SetEnvironmentVariable("LIBCLANG_PATH", "D:\LLVM19\bin", "User")
```

### 1.4 vcpkg（C/C++ 依赖管理）

```powershell
cd D:\
git clone https://github.com/microsoft/vcpkg.git
cd vcpkg
.\bootstrap-vcpkg.bat
[Environment]::SetEnvironmentVariable("VCPKG_ROOT", "D:\vcpkg", "User")
```

## 三、编译

### 3.0 每次编译前设置环境变量

把下面保存为项目根目录的 `env.ps1`，每次开终端先 `. .\env.ps1`：

```powershell
$env:RUSTUP_HOME = "D:\rust\toolchains"
$env:CARGO_HOME = "D:\rust\cargo"
$env:PATH = "D:\rust\cargo\bin;$env:PATH"
$env:VCPKG_ROOT = "D:\vcpkg"
$env:LIBCLANG_PATH = "D:\LLVM19\bin"
Write-Host "RustDesk build env ready"
```

### 3.1 安装 vcpkg 依赖包（首次/依赖变更时）

```powershell
cd D:\Projects\OtherProjects\rustdesk
D:\vcpkg\vcpkg.exe install --triplet x64-windows-static
```

需要的包（清单自动处理）：`opus`, `libvpx`, `libyuv`, `aom`, `ffmpeg`, `mfx-dispatch`, `libjpeg-turbo`

### 3.2 生成内嵌 UI（Sciter 版必须）

```powershell
python res/inline-sciter.py
```

### 3.3 编译产物

| 产物 | 说明 |
|------|------|
| `headless_sdk.exe` | 控制端，Python 通过 WebSocket 调用（custom 分支独有） |
| `rustdesk.exe` | 被控端，带 UI，接收控制端的键鼠/截图命令 |

---

#### Debug 版本（日常开发 headless）

```powershell
# 语法检查（最快，不生成 exe）
cargo check --bin headless_sdk

# 编译（~30s）
cargo build --bin headless_sdk
```

产物：`target\debug\headless_sdk.exe`

> **为什么 debug 不打 rustdesk：** debug 版不带 `inline` feature，启动时从当前目录找 `src/ui/`，双击跑不起来。被控端只用 release。

---

#### Release 版本（被控端）

```powershell
cargo build --release --features inline
```

产物：
- `target\release\rustdesk.exe`（约 30 MB，UI 内嵌，可拷贝任意运行）
- `target\release\headless_sdk.exe`（控制端）

### 3.4 编译命令速查

```powershell
# 设置环境
cd D:\Projects\OtherProjects\rustdesk
. .\env.ps1
python res/inline-sciter.py

# 日常调试 — 只打 headless
cargo build --bin headless_sdk

# 被控端发布
cargo build --release --features inline
```

## 五、踩坑记录

| 问题 | 原因 | 解决 |
|---|---|---|
| `Connection was reset` | GitHub 被墙 | 配代理 `git config --global http.proxy http://127.0.0.1:7897` |
| `VCPKG_ROOT not found` | magnum-opus 需要 vcpkg | 安装 vcpkg 并设环境变量 |
| `libclang not found` | bindgen 需要 libclang | 安装 LLVM 19，设 `LIBCLANG_PATH` |
| NASM 不兼容 | vcpkg 自带的 NASM 3.01 太新 | 换 NASM 2.16.03 |
| 所有 FFI 结构体为空 | LLVM 22 与 bindgen 不兼容 | 降级到 LLVM 19.1.7 |
| 双击 exe 没界面 | exe 从当前目录找 `src/ui/` | 启用 `inline` feature |
| `sciter.dll not found` | Sciter 运行时 DLL 缺失 | 下载 https://github.com/c-smile/sciter-sdk/raw/master/bin.win/x64/sciter.dll 放到 exe 同目录 |
| vcpkg 安装报文件占用 | Windows Defender 锁文件 | 临时关闭实时保护 |
